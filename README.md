# Sistema de Gerenciamento de Áreas Urbanas (C)

## 📌 Descrição

Este projeto foi desenvolvido em linguagem C como trabalho acadêmico com o objetivo de aplicar os conceitos fundamentais de programação estruturada na implementação de um sistema para gerenciamento de informações sobre áreas urbanas.

A aplicação permite registrar, consultar e manipular dados relacionados às áreas urbanas, utilizando estruturas de dados e funções para organizar as informações de forma eficiente. O projeto foi desenvolvido em ambiente de console, priorizando a organização do código e a modularização das funcionalidades.

## 🚀 Funcionalidades

* Cadastro de áreas urbanas.
* Consulta das informações cadastradas.
* Atualização dos dados de uma área.
* Remoção de registros.
* Listagem de todas as áreas cadastradas.
* Validação das entradas informadas pelo usuário.

## 🛠️ Tecnologias Utilizadas

* Linguagem C
* Programação Estruturada
* Interface via terminal (console)

## 📚 Conceitos Aplicados

Durante o desenvolvimento foram utilizados diversos conceitos da linguagem C, como:

* Estruturas (`struct`) para representar as áreas urbanas.
* Funções para modularização do sistema.
* Vetores para armazenamento dos registros.
* Estruturas condicionais e de repetição.
* Manipulação de strings.
* Organização e reutilização de código.

## 🎯 Objetivo

O principal objetivo deste projeto foi consolidar os conhecimentos em programação estruturada por meio da construção de uma aplicação prática, desenvolvendo habilidades de organização de código, manipulação de dados e implementação de funcionalidades típicas de um sistema de gerenciamento.
